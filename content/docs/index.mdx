Pre-built components using the [View Transitions API](https://developer.mozilla.org/en-US/docs/Web/API/View_Transitions_API) for smooth theme switching and page transitions. Install via the shadcn CLI.

## Setup

Add the transitions registry to your `components.json`:

```json
{
  "registries": {
    "@transitions": "https://github.com/nicholasgriffintn/page-transitions/raw/main/registry.json"
  }
}
```

```bash
npx shadcn@latest add @transitions/component-name
```

## How It Works

Each component injects CSS animations into `::view-transition-old(root)` and `::view-transition-new(root)` pseudo-elements, then triggers a view transition by toggling the `.dark` class on `<html>`. The transition CSS is bundled inside each component — no extra setup needed.

## Shared Props

All theme toggle components accept these props:

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `transition` | `string` | `"fade"` | Built-in transition name (see below) |
| `css` | `string` | — | Custom CSS to override the `transition` prop |
| `duration` | `number` | — | Override the animation duration (ms) |
| `easing` | `string` | — | Override the timing function |

Pass `css` with any valid `::view-transition-*` CSS to use a fully custom animation. When `css` is set, `transition`, `duration`, and `easing` are ignored.
